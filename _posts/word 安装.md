# ❤️1. 下载安装：
&emsp;&emsp;官网下载office tool plus：

有7z的推荐下载7z的压缩包 更加方便快捷。

# 🧡2.  解压
<font color="red">以管理员方式打开Office Tool Plus.exe</font>
&emsp;&emsp;把刚才下载的压缩包用解压工具解压缩，然后右键以管理员方式运行Office Tool Plus (PS:不以管理员方式运行有可能打不开或者报错。)

![在这里插入图片描述](https://img-blog.csdnimg.cn/95c0e246b6e04dabaae771892c820864.png)
<hr>

# 💛3. 移除
&emsp;&emsp;如果有未激活应用的先卸载 可以直接用Office Tool Plus移除
  &emsp;&emsp;如果有已经下载好的但是没有激活成功的word等软件，建议直接用此软件移除，能够完美的卸载，避免重装时各种卸载不完全不干净的麻烦。
office tool plus左侧第4个图标【工具箱】，点击【移除office】，点【开始】即可移除。

![在这里插入图片描述](https://img-blog.csdnimg.cn/e342f323ae444453a6414afcc75ca1b7.png)
<hr>

# 💚4. 安装部署
 --本文以2021专业增强版为例
&emsp;&emsp;点击左侧第二个按钮部署 
&emsp;&emsp;安装模块选office部署工具 其他诸如部署模式，体系结构，更新通道那些按照自己需求选择即可。

​![在这里插入图片描述](https://img-blog.csdnimg.cn/0c21e1b22c7647f582d04a1f96cb9d9f.png#pic_center)
&emsp;&emsp;产品点击添加产品 
![在这里插入图片描述](https://img-blog.csdnimg.cn/a8b0346fcb544043a717050f3cdfec87.png#pic_center)

 &emsp;&emsp;应用程序需要哪个就勾选哪个 根据个人情况判断![在这里插入图片描述](https://img-blog.csdnimg.cn/bda8fb6af7ef4b779e5ec4c48a8443e8.png)
 &emsp;&emsp;&emsp;在产品列表选择添加自己需要的产品即可 
 
 ![在这里插入图片描述](https://img-blog.csdnimg.cn/24a418f60c984a918d6d12b246a04048.png#pic_center)
 <hr>
 
# 💙5. 激活

 1. 点击左侧激活按钮
 2. 安装许可证
 3. 刷新许可证列表确定安装完毕许可证再设置KMS主机
 4. 最后激活
激活完毕显示【产品激活成功】就表示成功了 可以点开之前勾选任意的应用测试一下是否已成功激活。
kms主机可以自己搭建也可以网上搜索   填写之前看是否能ping通 ，哪个能ping通就用哪个

> 但是它需要一定的计算机技能和知识。如果遇到问题的话记得去看官方的文档或者下方评论。
